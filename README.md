# Beniflix for Android

[Download Beniflix 0.1.3](https://github.com/Benighter/Beniflix-Releases/releases/download/v0.1.3/Beniflix-0.1.3.apk)

A movie and TV app with a black and red interface and custom Beniflix branding with a Rust core, ad and popup blocking, Favorites, watched-episode markers, resume progress, subtitles, simultaneous episode downloads and whole-season downloads with duplicate prevention. Requires Android 8 or newer and an up-to-date Android System WebView. The APK includes ARM64 and x86_64 support.

Online titles, available qualities and subtitle tracks depend on the remote catalogue and video servers. Protected or live streams are not downloadable. Beniflix does not rehost media.

This repository contains signed APKs, update manifests, checksums and release notes only. Application source and signing material are kept private.

[Update manifest](https://github.com/Benighter/Beniflix-Releases/releases/latest/download/android-update.json). Android asks for approval before installing an update.
